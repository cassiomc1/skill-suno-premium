# Genre Catalog (81 Profiles Across 12 Musical Families)

These 81 profiles are curated **editorial starting points**, not rigid rules about musical traditions. Every production descriptor is written in English for Suno's Style field, while the sung lyric language remains completely independent.

> **Genre Sovereignty Rule**: Always preserve the selected genre's authentic rhythm, ensemble, harmony, and dynamic range. Never inject 4/4 house kicks, sidechain pumping, DJ intros, festival risers, or pop drops into non-electronic genres unless the user explicitly asks for a hybrid fusion.
